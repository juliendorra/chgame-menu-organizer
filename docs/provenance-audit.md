# CHGame Menu Organizer provenance audit

The official CHGame website was the reference for the SD workflow and for specific reconnect behavior. The reference implementation for standalone `.chgame` preparation was Kevin Bates’s Python CHGame CLI and the published format specifications. The Organizer directly reused the source of the website’s console-side helper from the public CHGame repository and built its own variant. Those three findings have different evidence.

This audit covers the source published through `1eea718` and the available Organizer and Pinball development records. Public attribution is documented in the [README](../README.md#credits-and-upstream-code). Dates below use Europe/Paris time. The browser comparisons use the official scripts served on 16 November 2026. Historical chat excerpts confirm particular downloads and inspections, with only partial coverage of what the site served during development. A source comparison can identify exact matches and similar logic. It cannot establish the source of every line or rule out an earlier or substantially rewritten match.

#### Code excerpts side by side

| Operation | Official browser code | Organizer browser code |
| --- | --- | --- |
| Read one chunk in the linked downloader | `const { done, value } = await reader.read();` | `const {done, value} = await reader.read();` |
| Count downloaded bytes | `size += value.byteLength;` | `size += value.length;` |
| Read one chunk after ZIP decompression | `if (done) break;` in the network reader | `if (done) break;` in the decompression reader |
| Sync and quit the SD helper | `return this.call(9);` and `return this.call(10);` | `return this.call(9);` and `return this.call(10);` |
| Attach the new folder to its parent | `tree.get(parent3).push({ folder: child });` | `tree.get(folder).push({title, child});` |
| Validate the license filename | `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` | `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` |
| Select a port from a disconnect event | `event.port \|\| event.target` | `event.port ?? event.target` |
| Filter out disconnected ports | `p.connected !== false` | `port.connected !== false` |

## Directly reused files and generated firmware

Compared against the public CHGame checkout pinned at `e1f8d05940ddb7bbef89c13326da75c003f02904`. Exact identity was checked by bytes. The helper’s upstream documentation says it was written for the website before moving into the published board package. The distributed binary is 22,304 bytes and matches the SHA-256 in `firmware/helper.json`. That checks the payload identity. It does not establish reproducibility with the public repository’s alternative Arduino build.
